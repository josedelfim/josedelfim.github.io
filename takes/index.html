Shooting notes in, organized checklist out

On set, someone types what was filmed into a plain notes file. The spreadsheet reads that file by itself, splits each line into fields, removes duplicates and sorts by date. Nobody retypes anything.

Why it matters

For the crewBefore wrapping a location, anyone can check coverage: do we have the sunrise shot? Which card is it on?
For the editThe editor starts from a clean list instead of scrolling through notes, and nothing filmed gets forgotten.

The trick is not the spreadsheet. It is letting people write the way they already write on set, and doing the organizing for them.
